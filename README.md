# 선형회귀 및 비선형회귀 프로그램

## 프로젝트 소개

본 프로젝트는 데이터처리개론 선형회귀 강의자료를 바탕으로 작성하였다.

단순선형회귀는 최소제곱법(Least Squares Method)을 이용하여 잔차 제곱합을 최소화하는 직선을 찾는다.

비선형회귀는 2차 다항식 모델을 이용하여 데이터를 곡선으로 근사한다.

## 사용 라이브러리

- NumPy
- Matplotlib
- SciPy

## 구현 내용

### 1. 선형회귀

회귀식

y = ax + b

- 경사하강법(Gradient Descent) 사용
- 회귀계수 a, b 계산
- 평균제곱오차(MSE) 계산

### 2. 비선형회귀

회귀식

y = ax² + bx + c

- curve_fit 함수 사용
- 평균제곱오차(MSE) 계산
